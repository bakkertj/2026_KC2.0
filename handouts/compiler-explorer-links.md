# Compiler Explorer links

One link per demo, preconfigured for x86-64 GCC 14.2 with `-std=c++23 -O2 -Wall -Wextra -Wpedantic` and an execution pane, so the program's output appears under the assembly. Click **run**; where a demo has deliberate errors behind `SHOW_ERRORS`, **errors** opens the same file with `-DSHOW_ERRORS` so you can read the diagnostics. Generated by `tools/godbolt-links.py`; do not edit by hand.

Demos that need more than one file or a library godbolt does not provide (`demos/s05/modules`, `demos/s04/parallel.cpp`) are built from the repo instead.
